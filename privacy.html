Privacy Policy

A simple website without behavioral tracking.

Game Master Society keeps this website intentionally straightforward. We do not use analytics, advertising trackers, tracking pixels, cookies, or browser storage to follow visitors.

Last updated July 14, 2026.

What this website does not collect

GMS does not use this website to create user accounts, build visitor profiles, record browsing histories, or store form submissions in a website database. We do not install analytics software, advertising technology, session-replay tools, tracking pixels, or social-media embeds.

GMS does not set cookies and does not use local storage or session storage in your browser.

How the inquiry forms work

The partnership and Game Master interest forms run in your browser and prepare an email addressed to GMS. Completing a form does not submit information to this website or save it in a website database. Nothing is sent until you review the prepared message and choose to send it through your email application.

If you send that email, its contents will be handled by your email provider, Google’s Gmail service, and the GMS inbox. GMS may retain and use the message as needed to respond to your inquiry.

Website hosting

This website is hosted through GitHub Pages. Like most web hosts, GitHub may process standard technical request information—such as an IP address, browser or device information, requested pages, and timestamps—to deliver and secure the site. GMS does not use that information for behavioral analytics and does not receive a visitor-tracking dashboard from this website.

External links

The site links to independent services and websites, including Discord, Instagram, email providers, and venue websites. Those services have their own privacy practices. Merely viewing a GMS page does not load a Discord, Instagram, or venue tracking embed; information is shared with those services only when you choose to follow a link or use their service.

Children’s privacy

This is a general-audience informational website. GMS does not knowingly use the website to collect personal information from children. A parent or guardian should handle any inquiry involving a minor.

Changes to this policy

If the website’s data practices change, this page will be updated so the policy continues to describe the site accurately.
